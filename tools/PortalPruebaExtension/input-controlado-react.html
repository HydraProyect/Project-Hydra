2. Input controlado (React)

El widget no lee input.files directamente al mostrar el nombre del fichero — lo hace a través del estado de React, actualizado en onChange. Si el evento sintético que dispara inyectarEnInput() no llega al onChange de React, el estado nunca se actualiza aunque el navegador sí muestre el fichero en el input nativo — ese desajuste es justo el riesgo que esta página comprueba.
